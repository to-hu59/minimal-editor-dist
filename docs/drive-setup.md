# Google Drive の設定（かんたん版）

> この文書は AI が書きました。画面の名前や手順は、Google や GitHub の変更で変わることがあります。

Google Drive と同期したい人だけ、この手順で自分用の設定を作ってください。使わない人は読まなくて大丈夫です。作品は、使っている端末の中に保存されます。

画像つきの詳しい説明は [くわしい版](drive-setup-detail.md) にあります。迷ったらそちらを見てください。

## 全体の流れ

1. Google のプロジェクトを作る
2. Google Drive API をオンにする
3. 同意画面を作る
4. クライアント ID を作る
5. アプリに ID を貼る
6. つないでみる

## はじめに

- パソコンかタブレットでの作業をおすすめします。スマホは画面が狭くて作業しにくいです。スマホで行うときは、ブラウザのメニュー（「⋮」など）で「PC版サイト」にチェック（✅）を入れてください。
- Google アカウントが必要です（無料）。
- アプリのアドレスは、次のとおりです。自分のアドレスを作りたい人は、一番下の「自分のアドレスを作りたい人へ」を見てください。

      https://to-hu59.github.io/minimal-editor-dist/
- Google の画面にお金の案内（「無料トライアルを試す」「無料で始める」など）が出ても、押さずに無視してください。この設定だけなら、お金はかかりません。
- 「課金」「請求先アカウントの作成」の画面が出たら、何も押さずに https://console.cloud.google.com/ を開き直してください。
- Google のホーム画面を下にスクロールすると出る「＋ Gemini API キーを作成する」などのボタンも、押さないでください。

## 1. Google のプロジェクトを作る

1. [「新しいプロジェクト」の画面](https://console.cloud.google.com/projectcreate) を開きます。
2. 「プロジェクト名」に好きな名前を入れます。最初から入っている名前のままでも大丈夫です。
3. 「作成」を押します。
4. 右上の「🔔」に「1」がつきます。押して、通知の「プロジェクトを選択」を押します。
5. 画面上部のプロジェクト名が、いま作ったものになっているか必ず確認します。前から持っているプロジェクトのままだと、そちらに設定してしまいます。

## 2. Google Drive API をオンにする

1. [Google Drive API の画面](https://console.cloud.google.com/apis/library/drive.googleapis.com) を開きます。
2. 画面上部のプロジェクト名が、手順 1 で作ったものか確認します。
3. 「有効にする」を押します。「API が有効です」と出れば完了です。

## 3. 同意画面を作る

1. [同意画面](https://console.developers.google.com/auth/branding) を開きます。
2. 「まだ構成されていません」と出たら「開始」を押し、4 つの画面を順に進めます。
   1. アプリ情報：「アプリ名」に好きな名前を入れます。「ユーザー サポートメール」には自分のメールアドレスを選んで「次へ」を押します。
   2. 対象：「外部」を選んで「次へ」を押します。「内部」は選びません。
   3. 連絡先情報：自分のメールアドレスを入れて「次へ」を押します。
   4. 終了：ポリシーへの同意にチェックを入れ、「続行」→「作成」を押します。
3. [「対象」の画面](https://console.developers.google.com/auth/audience) を開きます。
4. 「公開ステータス」が「テスト中」のままであることを確認します。「アプリを公開」は押しません。
5. 下にスクロールして、「テストユーザー」の「Add users」を押します。自分のメールアドレスを入れます。ほかに使う人がいれば、その人のメールアドレスも入れます。
6. 「保存」を 2 回押します。

## 4. クライアント ID を作る

1. [クライアントの画面](https://console.developers.google.com/auth/clients) を開きます。
2. 上の「⋮」（点が 3 つ）→「クライアントを作成」を押します。
3. 「アプリケーションの種類」は「ウェブ アプリケーション」にします。名前はそのままで大丈夫です。
4. 下にスクロールして、「承認済みの JavaScript 生成元」の「URI を追加」を押します。このアプリのアドレスの、前半だけを入れます。

       https://to-hu59.github.io

   ・末尾の「/」や「/minimal-editor-dist/」は付けません。
   ・パソコンで試すだけの場合は、「http://localhost:8000」も追加します。
   ・「承認済みのリダイレクト URI」は空のままにします。
5. 「作成」を押します。
6. 「クライアント」の一覧にある「クライアント ID」を、コピーします。「…apps.googleusercontent.com」で終わる長い文字です。横にスライドすると見えます。

## 5. アプリに ID を貼る

1. アプリを開きます（https://to-hu59.github.io/minimal-editor-dist/）。
2. 設定を開き、「Google Drive」の欄の「クライアントID」に、コピーした ID を貼ります。
3. 「IDを保存する」を押します。

ID は、使っている端末の中にだけ保存されます。

## 6. つないでみる

1. アプリを開き、本棚の上の「☁」を押します。
2. Google の画面でアカウントを選びます。
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「（アプリ名）に移動」を押します。自分で作ったアプリなので問題ありません。
4. つながると、Drive に「読書リーダー(仮)」というフォルダができます。

## 自分のアドレスを作りたい人へ

上のアドレスではなく、自分のアドレスで使いたい人は、アプリのコピーを作ります。GitHub Pages を使うと、無料で作れます。GitHub アカウントが必要です。

1. [GitHub](https://github.com/) にログインします（アカウントがなければ作ります）。
2. [配布版のページ](https://github.com/to-hu59/minimal-editor-dist) を開き、右上の「Fork」を押します。
3. 「Create fork」を押します。自分用のコピーができます。
4. 自分のコピーのページで「Settings」→ 左の「Pages」を開きます。
5. 「Branch」を「main」、フォルダを「/ (root)」にして「Save」を押します。
6. 1〜2 分待って、ページを開き直します。「Your site is live at …」とアドレスが出ます。

アドレスは、次の形です。

    https://自分のユーザー名.github.io/minimal-editor-dist/

このアドレスを開くと、アプリが動きます。

Google に登録するのは（手順 4）、「/minimal-editor-dist/」より前の部分だけです。

    https://自分のユーザー名.github.io

クライアント ID は、手順 5 と同じように、アプリの設定の欄に貼れます。コピーの「index.html」の「const DRIVE_CLIENT_ID_FIXED = '';」の引用符の間に貼って、保存してもかまいません（「Commit changes」を押します）。

手元のパソコンで試すだけなら、アドレスを作らなくても、「http://localhost:8000」で動きます。アプリのフォルダで、次のコマンドを実行します。

    python -m http.server 8000

## うまくいかないとき

「origin_mismatch」などのアドレスのエラーが出る
→ 手順 4 の「承認済みの JavaScript 生成元」に、いま開いているアドレスが入っていません。末尾に「/」が付いていないか、「http」と「https」を間違えていないか確認してください。反映まで 5 分ほどかかることもあります。

「アクセスをブロック」と出る
→ 手順 3 の「テストユーザー」に、そのメールアドレスが入っていません。

「☁」を押しても何も起きない
→ 設定の欄に ID を貼っていないか、貼り間違えています。

数日たつとつながらなくなる
→ 「テスト中」のままだと、許可が切れることがあります。もう一度「☁」を押して、許可し直してください。

## 気をつけること

- ログイン（Google の許可）は、約 1 時間で切れます。配布版は、つなぎ直しを自動で行う中継のサーバーを、通していません。そのため、**約1時間ごとに、同期のつなぎ直しが必要**です。切れたら、本棚の上の「☁」を押し直してください。小さい窓が、一瞬、出て、すぐ終わります。設定の Google Drive の欄に、「ログインが切れたら、さわったときに自動でやり直す」があります（はじめはオン）。オンなら、切れたあとに画面をさわると、小さな窓が一瞬ひらいて、つなぎ直します。
- クライアント ID は、人に見られても問題ありません。ただし自分のプロジェクトのものです。ほかの人にも使わせたい場合は、その人にそれぞれ作ってもらうほうが安全です。
- 作品の本文は、Drive にも置かれます。どの Google アカウントでつなぐか、気をつけてください。
