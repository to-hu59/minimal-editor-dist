# 読書リーダー(仮)

## ※最重要項目※

**これは、作者が自分のためだけに作った読書リーダーです。**
**永遠に未完成です。**
**思いつきで、機能を足したり、消したりします。**

- 演出（動きや画面の枠など）は、作ってあるのに、まだアプリに入れていないものが、たくさんあります。
- 「あとで入れよう」と思ったまま、そのままのものも、たくさんあります。
- 使えるものも、ある日、予告なく変わったり、なくなったりします。

ブラウザで動く、自分用の読書アプリです。作品（小説など）を本棚に登録して、読む・編集する・メモを残すことができます。
ホーム画面に追加すると、アプリのように使えます。特別なサーバーは要りません（リポジトリの中身を、ホームページの置き場に置くだけで動きます）。

> この版には、**フォントのファイルを入れていません**。ライセンスのページも空です（書き方の見本つき）。

## できること

**本棚・作品**
- 作品の登録（表紙・作者・レーベル・分類・タグ・状態・評価）
- 🔍検索：本棚では、言葉・作者・レーベル・年・評価・状態で絞り込み。作品の中では、本文・コメント・ウィキ・ノートを探せます

**読む**
- 縦スクロール／ページめくり（パソコンは見開きもできます）
- 文字サイズ（8〜28px）、行の間隔（1.0〜3.0）、紙の風合い（生成り・白紙・夜間灯）
- ルビ、読んだ位置（続きから）、コメント、読書ノート
- 日本語版の名前など、好きな名前に変えられます（一括置換。本文は変えずに、表示と読み上げだけ置き換えます）
- 音読（ブラウザの読み上げ。パソコンでは VOICEVOX も使えます）

**編集**
- 本文の編集、ルビ、OCR（画像から文字を起こす）、「本文を整える」
- 画面の枠：システム画面・ステータス・クエスト・掲示板・通話・1行の通知など
- 文字の向き：一部だけの縦書き・ななめ・反転・回転

**演出（本文に印を書くと動きます）**
- 掲示板のタイプ音、［着信］［バイブ］［怒鳴り］［ジジッ］［頭痛］［どくん］など
- 音と振動は、設定で「音を出す」「振動する」をONにしたときだけ出ます

**ウィキ**
- カテゴリ分け、項目ごとの欄（ステータス・所持品・スキル・関係など）
- 本文の中のウィキの言葉にうっすら色がつき、押すとカードで見られます（読んだ話までだけ表示。先の設定は伏せます）

**そのほか**
- 書体の追加（自分のフォントを入れる）、Google ドライブとの同期、ネットなしで開く（ホーム画面に追加したとき）
- Google ドキュメントへの書き出し（本文のみ・演出なし）

## 使い方

1. このリポジトリを Fork して、自分の GitHub Pages に置きます（Settings → Pages → Branch を main、フォルダを / (root)）。
2. 出てきたアドレスを開くと、アプリが動きます。
3. Google Drive と同期したい人は、[かんたん版の手順書](docs/drive-setup.md)（画像つきは [くわしい版](docs/drive-setup-detail.md)）を見てください。

## 注意

**フォントとライセンス**
- フォントのファイルは入っていません。自分で入れるときは、アプリの設定の「フォントを追加」から入れます。**入れたフォントは、その端末の、そのアプリの中だけに保存されます。**
- フォントごとに、使っていい範囲（人に配る・アプリに入れる・商売に使う）が違います。配布元の決まりを、必ず確かめてください。
- 使ったフォントや素材の作者・決まりは、`licenses.html` に自分で書けます（書き方の見本は、そのファイルの中のコメントにあります）。空のままでも動きます。
- フォントを入れないと、画面の字体は、端末にもともと入っている明朝体・ゴシック体になります。

**保存**
- 作品は、ブラウザの中の保存場所（localStorage といいます）に入ります。**入る量は、約5MBまでです。** 長い作品をたくさん入れると、いっぱいになります。
- ブラウザの保存データを消すと、作品も消えます。大事な作品は、Google ドライブか書き出しで、別にとっておいてください。
- ブラウザを変えたり、ホームページのアドレスが変わったりすると、別の保存場所になります（前の作品は見えなくなります）。

**Google ドライブとの同期**
- つないでいるときは、**ドライブが本体で、端末のものは写し**です。別の端末で変えると、ドライブから取ってきます。両方で変えたときは、新しいほうを使い、もう一方はドライブに控えとして残します。
- ドライブに作られるフォルダの、はじめの名前は「読書リーダー(仮)」です。**ドライブ側で、好きな名前に変えられます**（フォルダは名前ではなく、印で見つけているので、変えても同期は切れません）。
- **そのままでは、Drive にはつながりません。** コードの中の `DRIVE_CLIENT_ID`（`index.html` の中）が、作者の Google の設定につながっているからです。自分で使うときは、Google Cloud で、自分用の「OAuth クライアントID」というものを作って、置き換えてください。読み書きする範囲は「このアプリが作ったファイルだけ」です。
- 自動の同期は、**はじめは切**です（電池のため）。設定のドライブの欄で入れられます。切のときは、上の☁か「いま同期する」を押したときだけ同期します。
- 作品の本文は、ドライブにも置かれます。他の人に見せたくないものを入れるときは、どのGoogleアカウントでつなぐかに、気をつけてください。

**音声・音**
- 音読の「ずんだもん」は、パソコンで VOICEVOX を起動して使います（スマホでは使えません）。使うときは、**「VOICEVOX:ずんだもん」のクレジット表記が要ります。**
- 振動は、ブラウザが対応しているときだけです（iPhone の Safari は、振動に対応していません）。

**同梱のもの**
- `fx/` は、演出の部品です。`fx/a/` の画像は、**公開する前に、使ってよい画像か確かめてください。**
- 画面の見た目を作る部品の一部は、インターネット上のものを読み込んでいます。**ネットがない状態で最初に開くと、見た目がくずれることがあります。**（一度開けば、保存されて、ネットなしでも開けます）

## 動作確認

- パソコンと Android の Chrome で確認しています。iPhone の Safari は、ホーム画面に追加して使えますが、すべての動き（振動など）は確かめていません。
- 新しいブラウザが必要です。古いブラウザでは、動かないことがあります。
