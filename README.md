# 読書リーダー(仮)

ブラウザで動く、作者が自分のために作った読書アプリです。永遠に未完成です。

**説明書は、Word の文書にしてあります。** この画面（GitHub）をブラウザで自動翻訳すると、文字が書き換わってしまうことがあるためです。ダウンロードして、Word で開いてください。

- [README.docx](README.docx)：アプリの説明・できること・注意
- [docs/drive-setup-easy.docx](docs/drive-setup-easy.docx)：Google Drive の設定（かんたん版）
- [docs/drive-setup-detail.docx](docs/drive-setup-detail.docx)：Google Drive の設定（くわしい版・画像つき）
- [docs/effects.docx](docs/effects.docx)：特殊演出の書き方

すぐ試すときは、次のアドレスを開きます。

https://to-hu59.github.io/minimal-editor-dist/

画面の文字がおかしいときは、ブラウザの自動翻訳を、止めてください。
